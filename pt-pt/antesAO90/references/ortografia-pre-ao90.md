# Ortografia pré-AO90 (norma de 1945, uso português)

Referência rápida para escrever e para converter texto em AO90 para a grafia antiga. Em caso de dúvida, consultar o Priberam com a opção "grafia antes do Acordo".

## 1. Consoantes mudas (c, p) — repõem-se

| AO90 | Pré-AO90 |
|---|---|
| ação, reação, direção, coleção, correção, proteção | acção, reacção, direcção, colecção, correcção, protecção |
| ato, atual, atualmente, atividade, ativo, ator, atriz | acto, actual, actualmente, actividade, activo, actor, actriz |
| diretor, direto, direção, arquitetura, arquiteto | director, directo, direcção, arquitectura, arquitecto |
| exato, exceção, exceto, excecional | exacto, excepção, excepto, excepcional |
| projeto, objeto, objetivo, trajeto, sujeito* | projecto, objecto, objectivo, trajecto, sujeito (*sem c) |
| efetivo, afetar, afeto, afetivo, coletivo, seleção | efectivo, afectar, afecto, afectivo, colectivo, selecção |
| elétrico, eletricidade, eletrónico | eléctrico, electricidade, electrónico |
| letivo, dialeto, intelecto (igual), setor | lectivo, dialecto, intelecto, sector |
| ótimo, ótica, ótico, adotar, adoção | óptimo, óptica, óptico, adoptar, adopção |
| receção, receber (igual), recetor, conceção, perceção, perceber (igual) | recepção, receptor, concepção, percepção |
| aspeto, espetáculo, espetador, espetro, perspetiva, retrospetiva | aspecto, espectáculo, espectador, espectro, perspectiva, retrospectiva |
| batismo, batizar, Egito | baptismo, baptizar, Egipto |
| exceção, interceção, infeção, inspeção | excepção, intercepção, infecção, inspecção |

**Não alterar** (a consoante pronuncia-se e manteve-se no AO90 em PT): facto, pacto, contacto, ficção, convicção, egípcio, rapto, núpcias, apto, compacto, intacto, característica, eclipse, adepto, pictórico, erupção, corrupção, opção, captar, abrupto.

## 2. Acentos diferenciais — repõem-se

- **pára** (verbo parar) ≠ para (preposição): *O comboio não pára aqui.*
- **pêlo** (substantivo) ≠ pelo (por + o); **pélo, pélas** (verbo pelar)
- **pólo** (desporto, extremidade) ≠ polo (por + o, arcaico)
- **pêra** (fruto) ≠ pera (preposição arcaica)
- **pôr** (verbo) e **pôde** (pretérito) mantêm-se como no AO90.
- "voo", "enjoo", "creem", "leem", "veem" já não tinham acento em PT-PT antes do AO90: **não acrescentar acento**.

## 3. Hífen

| AO90 | Pré-AO90 |
|---|---|
| fim de semana, dia a dia (subst.), cor de rosa | fim-de-semana, dia-a-dia, cor-de-rosa |
| hei de, hás de, há de, hão de | hei-de, hás-de, há-de, hão-de |
| autoestrada, autoestima, autoavaliação | auto-estrada, auto-estima, auto-avaliação |
| coautor, coerdeiro, cooperar (igual) | co-autor, co-herdeiro, cooperar |
| antissemita, antirreligioso, anti-inflamatório (igual) | anti-semita, anti-religioso, anti-inflamatório |
| contrarregra, contrassenso | contra-regra, contra-senso |
| paraquedas, paraquedista, para-choques | pára-quedas, pára-quedista, pára-choques |
| extraescolar, infraestrutura, ultrassom | extra-escolar, infra-estrutura, ultra-som |
| semiaberto, semicírculo (igual) | semi-aberto, semicírculo |
| minissaia | mini-saia |
| mandachuva | manda-chuva |

Regra útil: antes do AO90, prefixos como *auto-, contra-, extra-, infra-, intra-, neo-, proto-, pseudo-, semi-, supra-, ultra-* levavam hífen antes de **vogal, h, r, s**; *anti-, arqui-, sobre-* antes de **h, i, r, s**. Em caso de dúvida, verificar.

## 4. Maiúsculas

- **Meses e estações do ano com maiúscula:** Janeiro, Fevereiro, … Dezembro; Primavera, Verão, Outono, Inverno.
- **Pontos cardeais** com maiúscula quando designam regiões: o Norte, o Sul.
- Dias da semana com minúscula (segunda-feira, sábado).
- Disciplinas e domínios do saber com maiúscula: a Filosofia, a História, a Literatura Portuguesa.
- Formas de tratamento abreviadas: Sr., Sr.ª, D., Dr., Dr.ª, Prof., Prof.ª.

## 5. Outros pontos

- Sem trema: cinquenta, frequente, linguística.
- "Óptimo", "baptismo", "Egipto"; "súbdito" e "amnistia" escrevem-se assim em PT antes e depois do AO90 (não confundir com o brasileiro "súdito", "anistia").
- "Facto" (acontecimento) ≠ "fato" (vestuário). Nunca converter um no outro às cegas.
- Ao converter um texto inteiro, rever palavra a palavra as terminações -ção, -tor, -tivo, -to, porque nem todas as palavras com essas terminações tinham consoante muda (ex.: *eleição, situação, autor, motivo, gato*).
